# 产品待办列表

这是唯一的需求入口。所有想做的功能、要修的缺陷都先进这里，再按优先级被挑进迭代。

## 使用规则

- 每条需求一个编号，用户故事用 `US-xxx`，缺陷用 `BUG-xxx`，编号只增不减、不复用。
- 新需求先写一行进表格，需要详细描述时再按 `templates/user-story.md` 建独立 spec 文件。
- 按优先级从上往下排，排序由产品负责人在迭代计划前维护。
- 被选进迭代后，把"迭代"列填上编号；完成后状态改为"完成"，不要删行。
