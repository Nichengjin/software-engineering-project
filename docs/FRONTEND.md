# 前端协作说明

前端为 React + TypeScript + Vite + TanStack Router SPA，位于 `apps/web`。依赖版本由根 npm workspace 和 lockfile 统一管理；共享 DTO 来自 `@wylie/contracts`，接口路径、权限和失败语义以 [HTTP 契约](design-docs/api-contract.md) 为准。

## 启动与同源联调

```sh
npm ci
npm run build -w @wylie/contracts
npm run dev -w @wylie/web
npm run typecheck -w @wylie/web
npm run build -w @wylie/web
npx vitest run apps/web/src/lib
```

Vite 绑定 `0.0.0.0:5173`，`/api` 代理到 `127.0.0.1:3000`，保留浏览器 Origin；API 的 `PUBLIC_ORIGIN` 应与浏览器实际访问入口一致。允许本地 host 与 Amp `.onamp.dev` portal host，不采用 `allowedHosts: true` 或任意 CORS。生产由 Hono 同源托管构建后的 SPA，Vite preview 只用于查看构建，不替代生产 API。

orb 使用已声明的 `amp orb services ensure`；没有服务声明时用 `amp orb service start web --command 'npm run dev -w @wylie/web' --port 5173 --portal`。分享命令实际返回的 portal URL，不分享 loopback 地址。portal 入口变化时同步 API 可信 Origin，不关闭 CSRF。

## 页面与数据边界

- 登录恢复 `/auth/me`，首次改密前不挂载业务页，退出调用真实接口；cookie `credentials: include`，写请求携带内存中的 `X-CSRF-Token`。不把 session、密码、CSRF 或人员凭据放入 localStorage。
- 学生：目录、主备选有序编排、保存、提交、删除确认、独立有效注册、变更通知、上一完成学期成绩单。保存不占位；首次提交 4+2，后续 1–4 主选与 0–2 备选；额满仍可备选。保留本人已有注册的主选不因额满被前端禁选，最终以服务端校验为准。
- 教授：资格／归属约束授课选择、版本校验、本人有效名册、上一完成学期逐格录分。空值不修改，失败格保留输入；不显示 SSN，不支持清除成绩。
- 教务：师生搜索分页与 CRUD、账户停用、人员状态影响预览＋确认 token、一次性初始凭据、四类 xlsx 上传和逐行结果、学期窗口、关闭异步状态、调剂／取消／未解决问题、账单送达状态与关闭后补选。计费表与调剂／未解决列表用学号和姓名标识学生，可按学号或姓名筛选，不向教务展示内部 UUID；业务编号只放在版本单元格的悬停提示里。
- 前端角色导航只改善交互，不能作为权限边界；所有权限、人员状态、时间、容量和事务规则必须由 API 重新判断。生产组件没有 fixture 分支或硬编码成功。

## 轮询与本地编辑

可见选课页每秒读取目录、课表和通知；授课、名册、关闭状态与受影响数据同样每秒刷新。每个 resource 的刷新循环只允许一批请求在途；请求耗时超过一秒时等待完成再读，不并发堆积。卸载取消请求，隐藏标签停止后续轮询，恢复前台立即重读。读取失败保留最后成功数据并明确显示连接异常；超过五秒未更新显示警告，不声称实时。

学生选择、教授授课和学期窗口使用独立本地编辑副本与原始 `version`。服务器高版本到达时，dirty 副本不被替换、合并或重标新版本，提交禁用；页面显示服务器选择供对照，用户确认后才丢弃本地副本。成功写入后的迟到低版本轮询不会回滚已确认副本。409 不自动重提；未知网络结果先查询，不重复非幂等写。刷新／关闭页面时浏览器提示本地未保存编辑；离开业务页面会卸载其本地副本。

## 组件与样式

`routes/` 按业务职责拆分学生、教授、人员、导入、窗口、关闭和补选；`components/` 只放真实复用的表格、反馈、加载／空状态和确认弹窗；`lib/` 管理 fetch、身份、学期、轮询与格式。web 不依赖 DB 或 API 私有模块。

视觉沿用已选 A 方向：navy 左导航、浅灰工作区、白色业务表格、右侧选择汇总、蓝色主按钮。颜色与布局由 `styles.css` 统一；不运行外部字体请求。窄屏下汇总堆叠到表格下方，表格自身横向滚动而非页面溢出；带“操作”列的表格（课程目录、人员列表）用 `sticky-actions` 把操作列固定在右侧，1280px 等常见投影宽度下按钮不被截断。

界面文案面向学生、教授和教务员，写成用户能直接照做的说明，不使用“送达事实”“越权”“基线”“≠”等开发和测试术语；业务规则的精确口径留在需求、契约和测试文档里。

表单必须有中文 label；按钮可键盘聚焦，备选排序有独立可访问名称；业务导航有 `aria-label` 和当前页标识。确认用原生 `<dialog>`，默认聚焦取消按钮、Escape 可取消（提交在途除外），焦点限制在弹窗内。失败用 `role=alert`，成功用 `role=status`，不以颜色单独表达状态。人员／导入初始凭据不保存到浏览器，关闭显示或离开页面后不可重新查询；截图验收避免包含凭据。

## 人机界面设计：课程 6.3 对照（US-030）

| 设计问题 | 当前页面的具体处理 | 验证与改进边界 |
| --- | --- | --- |
| 响应时间 | 读取显示加载状态；写入时禁用相关按钮；选课与关闭状态每秒轮询，超过五秒未更新提示连接问题 | 一秒是调度间隔，实际延迟依赖网络与服务耗时；传播计时和负载结果分别见测试报告 |
| 用户帮助 | 页面解释保存不占名额、首次 4＋2、合法成绩与导入格式；三角色操作步骤集中到 [用户手册](USER_MANUAL.md) | 当前为内联帮助与手册，没有额外帮助中心；Alpha 试用将检验是否能独立完成任务 |
| 出错处理 | 选课显示对应班次／规则问题，版本冲突要求先读取最新数据；导入按行、录分按格显示处理结果；失败输入保留供修改 | 网络结果未知时先核对服务器结果，避免重复提交；错误文案用用户可理解的动作说明 |
| 命令交互 | 主选／备选／移除／排序有明确按钮；提交、删除、关闭等动作有确认；默认焦点位于取消，Escape 可取消，按钮与标签支持键盘 | 前端禁用状态不能替代 API 权限；本轮不声称完成全部辅助技术或 Windows 浏览器验证 |

BUG-001 是界面设计的具体改进实例：教务计费列表从内部编号改为学号和姓名；1280px 宽度下的目录操作列固定在右侧；提示文字改为日常用语。测试报告保留修复前失败及修复后浏览器检查。图表和手册使用虚构数据，初始密码展示必须先隐藏再截图。
