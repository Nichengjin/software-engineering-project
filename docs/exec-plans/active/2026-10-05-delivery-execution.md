## 风险与回退

| 风险 | 缓解／回退 |
| --- | --- |
| 多 orb 契约漂移、未推送变更漏传 | 共同契约＋明确文件归属，传输后统筹统一 typecheck／真实测试；不覆盖未知 worktree |
| 单实例 gate／关闭写锁错误 | 提供可控屏障和故障 hook；保持人员→学期锁序；不加多实例部署 |
| outbox 丢失／重复计费 | 同事务持久化、60 秒固定重试、业务标识及版本替换；失败只重发不重新调剂 |
| 为速度误称指标达标／人类验收 | 区分文档检查、模块自测、独立测试、团队评审、教师验收；每条证据真实记录 |
| 新迁移毁共享数据 | 仅 disposable DB 迁移／reset；共享环境或生产写入需要明确批准，保留迁移回退说明 |
| 模拟系统／六人组队课程口径未确认 | 倪成锦交付前与课程教师确认，保留原待办，不以授权实现代替教师同意 |
