工程网络


n 工程网络是制定进度计划时另一种常用的图形工具；

n 它能描绘任务分解情况以及每项活动／作业的开始时
  间和结束时间，此外，它还显式地描绘各个作业彼此
  间的依赖关系；
n 工程网络图要求绘制者理解项目中哪些部分可以并行；
工程网络

注意区分活动与里程碑：
n 活动（Activity）：一个活动是项目的一部分，它要耗费一

 段时间，有开始和结束。
n 里程碑（Milestone）：一个里程碑是某个活动完成的标志，

 它是一个特定的时间点。
n 用箭头表示活动／作业；

n 用圆圈表示里程碑／事件。

n 活动的四个参数：
 n 前置条件(Precursor)：活动开始前必须发生的事件。

 n 持续时间(Duration)：完成活动所需的时间。

 n 最终期限(Due Date)：日期，活动必须在此之前完成。

 n 结束点(Endpoint)：通常是活动对应的里程碑或可交付成果。

估算工程进度


n 首先，把每个作业估计需要使用的时间写在表示
 该项作业的箭头上方。
n 其次，为每个事件计算下述两个统计数字：最早
 时刻EET和最迟时刻LET。
 估算工程进度

n 事件的最早时刻（EET）是该事件可以发生的最早时间：

 n 第一个事件的最早时刻定义为零。其他事件的最早时刻在工程网
  络上从左至右按事件发生顺序计算：
 n （1）考虑进入该事件的所有作业

 n （2）对于其中每个作业都计算它的持续时间与其起始事件的EET
  之和
 n （3）选取上述和数中的最大值作为该事件的最早时刻EET
 估算工程进度

n 事件的最迟时刻（LET）是在不影响工程竣工时间的前提下，
该事件最晚可以发生的时间：
 n 最后一个事件（工程结束）的最迟时刻就是它的最早时刻。其他
  事件的最迟时刻在工程网络上从右至左按逆作业流的方向计算。
 n （1）考虑离开该事件的所有作业

 n （2）从其中每个作业的结束事件的LET中减去该作业的持续时间

 n （3）选取上述差数中的最小值作为该事件的最迟时刻LET
机动时间（Slack Time）

n 一个作业可以有的全部机动时间等于它的结束事件的
 最迟时刻减去它的开始事件的最早时刻，再减去这个
 作业的持续时间：
   机动时间＝(LET)结束 －(EET)开始－持续时间
   机动时间＝可用时间－持续时间
   机动时间＝作业最晚开始时间－最早开始时间
   机动时间＝作业最晚结束时间－最早结束时间

    关键路径（Critical Path）

n   关键路径：
    u   充分条件：
        • 关键路径是一个工程网络图中最长（指持续时间最长，而非经过的活
          动最多）的路径。
        • 其上的每个活动对应的机动时间（Slack Time）都为零。
    u   必要条件：
        • 组成关键路径上的事件的最早时刻和最迟时刻相同。
关键路径（Critical Path）

 n 关键路径上的事件（关键事件）必须准时发生，组
  成关键路径的作业（关键作业）的实际持续时间不
  能超过估计的持续时间，否则工程就不能准时结束。
 n 使用关键路径法可以得出完成项目所需的最少时间。

 n 关键路径可能有多条。

 n 在工程网络图中关键路径用粗线箭头表示。
现实中的关键路径法

n 各活动所需时间通常仅仅是一个估计值

n 现实中关键路径上每个活动的空闲时间不一定为零，
 但该路径的空闲时间总和最小
n 关键路径的压缩

n 对于一个几乎是单线条的项目，或者含有循环活动
 的项目，关键路径法作用不大
