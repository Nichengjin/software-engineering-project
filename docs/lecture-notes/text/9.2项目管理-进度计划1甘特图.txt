项目进度计划（Project Schedule）

 n 项目开始阶段常被问到的两个问题：
   n 产品开发需要多长时间？

   n 产品开发成本是多少？

 n 项目进度计划：
   n 列举项目的各阶段

   n 把每个阶段划分成需要完成的活动

   n 描述活动间的关系

   n 估算活动所需的时间

工作分解结构（Work Breakdown Structure）

 n 工作分解结构（WBS）：
   n 是以可交付成果为导向的对项目成分的分组。

   n 自顶向下逐层构建，表现形式可以是图表也可以是文
    字大纲。
   n 最高层是项目本身；接下来是项目的可交付成果以及
    进一步分解的、更小的可交付成果；然后就是创建这
    些成果的活动。

Gantt图




 n Gantt（甘特）图是历史悠久、应用广泛的制定
   进度计划的工具
 Gantt图

n 假设有一座陈旧的矩形木板房需要重新油漆。这项工作必
须分3步完成： 首先刮掉旧漆，然后刷上新漆，最后清除
溅在窗户上的油漆。假设一共分配了15名工人去完成这项
工作，然而工具却很有限： 只有5把刮旧漆用的刮板，5把
刷漆用的刷子，5把清除溅在窗户上的油漆用的小刮刀。
 Gantt图

n 安排1：

n 首先刮掉四面墙壁上的旧漆，然后给每面墙壁都刷上新漆，
  最后清除溅在每个窗户上的油漆。
n 显然这是效率最低的做法，因为总共有15名工人，然而每
  种工具却只有5件，这样安排工作在任何时候都有10名工人
  闲着没活干。
 Gantt图

n 安排 2：

n 首先由5名工人用刮板刮掉第1面墙上的旧漆(这时其余10名
 工人休息)，当第1面墙刮净后，另外5名工人立即用刷子给
 这面墙刷新漆(与此同时拿刮板的5名工人转去刮第2面墙上
 的旧漆)，一旦刮旧漆的工人转到第3面墙而且刷新漆的工
 人转到第2面墙以后，余下的5名工人立即拿起刮刀去清除
 溅在第1面墙窗户上的油漆，……

n Gantt图能很形象地描绘任务分解情况，以及每个子任务(作业)
  的开始时间和结束时间，因此是进度计划和进度管理的有力工
  具。它具有直观简明和容易掌握、容易绘制的优点，但是Gantt
  图也有3个主要缺点：
  n   (1) 不能显式地描绘各项作业彼此间的依赖关系；
  n   (2) 进度计划的关键部分不明确，难于判定哪些部分应当是主攻和主控
      的对象；
  n   (3) 计划中有潜力的部分及潜力的大小不明确，往往造成潜力的浪费。
