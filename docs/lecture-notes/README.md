提取工具为 Poppler `pdftotext` 25.05.0，使用 `-layout -enc UTF-8`；以同版本 `pdfinfo` 核对页数。没有进行 OCR，也没有用生成式模型改写、纠错或补写课件正文。单文件提取命令示例：

